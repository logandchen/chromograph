Use your colors on any web page

Two ways, both using the palette and blend settings from this app. Colors adjust to each page: soft pastels behind dark text, deep shades behind light text.

Bookmark button (any browser, no install)

  1. Show your bookmarks bar, then drag this button onto it:

Chromagraph

  1. On any page, select some text and click the bookmark. Only that text gets colored.
  2. Click it with nothing selected to color the whole page; click again to clear.

The bookmark carries your current palette and settings. If you change them, drag the button up again.

Chrome extension (right-click menu + shortcut)

  1. Open chrome://extensions and turn on Developer mode.
  2. Click “Load unpacked” and choose the extension folder that sits next to this page.
  3. Here, go to Palette → “Copy palette code”, then paste it into the extension’s popup and press Save.
  4. Select text on any page → right-click → “Color this text”, or press Alt+Shift+C.

Works in Chrome, Edge, Brave and Arc.
